Profile photos.

- Add a profile photo on My Profile, or for any user you manage on their Edit
  User screen. It saves straight away — JPG, PNG, GIF or WebP, up to 5 MB.
- The photo appears in the author box, next to the author's name under a post's
  title, and on post cards. Without one, initials are shown as before.
- New REST API endpoints to read, set and remove profile photos; the API
  Reference lists them.
- Fixed: a database error could turn the error page into a blank page.
