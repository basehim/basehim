Switching a post to the visual editor now gives you real, editable blocks.

Before, a post written in HTML — including every post imported from WordPress —
opened in the visual editor as one big code box. Now it is split into
paragraphs, headings, images, lists, quotes and code, so you can add an image
between two paragraphs, move a section, or select text and add a link.

Anything the visual editor cannot show exactly — a table, a video embed, a form —
is kept as it is in its own HTML block, so nothing on the page changes. A short
note tells you what was converted. If you don't like the result, leave without
saving and the post stays as it was.
