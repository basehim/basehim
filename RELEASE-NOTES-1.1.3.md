A new theme, and a fix for themes with more than two menus.

**Circuits DIY** is a publication theme for an electronics site: a project grid,
a category mega menu that opens as a multi-column panel, a utility bar for
policy pages, and a four-column footer. It has twenty-five Customizer options —
colours, fonts, text size, page width, cards per row, card style, and toggles for
the author, view count, date, reading time and excerpts. All of them update the
live preview as you change them.

**Themes can now read any menu location they declare.** Previously only the
primary and footer menus reached a template, so a theme with its own locations —
a utility bar, separate footer columns — found them empty with no explanation.
Theme authors can now use `menu_at('location')` for any location the theme
declares.

To use the new theme: Appearance → Themes → activate Circuits DIY, then
Appearance → Customize to set the colours and layout.
