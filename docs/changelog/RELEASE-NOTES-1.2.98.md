A friendlier installer, and a default theme that makes a better first impression.

- The installer has been rebuilt with the Basehim logo and four clear steps: a server check, your database, your site and account, and a "your site is ready" screen with first steps. That last screen was never shown before.
- Database problems are explained in plain words, with what to check, instead of raw server errors.
- New sites get the tagline and timezone you choose, a Home and About menu, and starter content only if you want it.
- Servers without the GD image extension can now install Basehim; it's recommended rather than required.
- Default theme: the newest post leads the home page, posts without an image get a neat placeholder, the site name shows on phones, the header menu is properly spaced, and the 404 page and footer are tidier.
- An author with one post no longer shows "View all 1 posts".

After updating: nothing to do. If your site uses the default theme, its home page now leads with your newest post.
