The post and page lists match the Quick Edit dialog, especially on phones.

- On phones and tablets, each post is a cleaner card: title, slug and status
  at the top, then author, categories, date and the other columns in two
  tidy columns. The ⋮ button is easier to tap.
- Selected items are highlighted, so you can see what a bulk action will
  change.
- On phones and tablets the Table / List / Grid switch and the Density
  option are hidden, since only cards show there. Your choice still applies
  on a computer.
- On phones, the search box and the Screen Options button share the top
  line, the filter menus fit the screen, and tapping the search box no longer
  zooms in.
- Lists use the same, less rounded corners as the admin menu and Quick Edit.
