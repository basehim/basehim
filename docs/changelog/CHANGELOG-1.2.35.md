# Basehim 1.2.35

## Settings › Email

- **From Name is filled in.** The field now shows the name emails are sent
  under — your site name unless you typed another — instead of an empty box.
- Leaving it empty, or setting it to the site name, keeps it in step with
  the site name, so renaming the site also renames the sender.
- Line breaks are stripped from the From Name before it goes into a header.
