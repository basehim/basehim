Fixes for the sticky lists introduced in the last update.

- **The column headings now stay put correctly** when you scroll — before, they
  could disappear on some pages.
- **Screen Options now scrolls** when it has a lot in it, so nothing is cut off,
  and it opens in the right place whether the sticky header is on or off.
- **Scrolling quickly no longer makes anything jump.**
- **Changing the number of rows per page** takes you back to the first row.
- **On phones** the sticky controls now sit flush under the top bar with no odd
  rounded corner.

Both sticky options remain in Screen Options, on by default. After updating:
nothing to do.
