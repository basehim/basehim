A polish release for lists (posts, pages, comments and the rest), from a full
design review.

- **On phones, the search bar no longer touches the top bar when you
  scroll.** It now has even space above and below, runs edge to edge like an
  app, and turns frosted when it sticks.
- **Easier to tap on phones.** The tick boxes on each item are much easier to
  hit, all the buttons in the search row are the same size, and the page
  numbers at the bottom fit on one slim row.
- **Buttons look the same everywhere.** The bar that appears when you select
  items, the page numbers, the view switch and the All / Trash switch now use
  the same buttons as the rest of the admin.
- **Tidier tables on computers.** Dates and web addresses stay on one line,
  the Views number lines up with the rest of the row, and every control in the
  search row is the same height.
- **Wide tables behave better.** The search row stays on one line on tablets,
  titles stay readable, and a fade at the edge shows there's more to scroll.
- **Empty searches say "No posts"** instead of "Showing 0–0 of 0".
