Fixes for the RSS feed, post dates and comment moderation.

- RSS feed: posts now appear as proper text and images, with full image
  links, so Pinterest and feed readers can use them. Each item includes its
  featured image (or the first image in the post).
- Post dates: a new post can be given an earlier date and time ("Set date" in
  the Publish box), so posts are listed in the order of the times you choose.
- Comments: Approve, Unapprove, Spam and Delete on the Comments screen work
  again (they showed a "not found" page).

After updating: nothing to do. Pinterest and other services pick up the
improved feed the next time they check it.
