First run and local development.

- Opening a new, not-yet-installed site now takes you to the installer. Before,
  the first page showed "500 Internal Server Error" until you opened
  /install.php yourself.
- Run Basehim on your own computer with PHP's built-in server:
  `php -S localhost:8000 server.php`, then open http://localhost:8000.
- The README has a Quick start for web hosting, local development and git.
- Installed sites: nothing changes.
