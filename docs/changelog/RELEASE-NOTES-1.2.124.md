- **Safer content folder.** Only images, styles, scripts, fonts and media
  can be downloaded from `content/`. Template backups (like
  `single.php.bak`), zips, notes and manifests left there are no longer
  public.
- **One list of server requirements** for the installer and System →
  Health. Health now checks the Zip extension, which updates and theme and
  app installs need. It checks the uploads folder Basehim actually uses, and
  says what a missing item affects.
- **AI assistants can manage menus, themes and settings** through MCP:
  - build or change a menu in one step;
  - switch the theme;
  - change Customize options;
  - change General, Reading, Writing, Discussion, SEO and Appearance
    settings, with the same checks as the Settings screens.

  Security, sign-in, email and permalink settings stay dashboard-only.
- **Menus use your theme's locations.** The Menus screen now offers your
  theme's own locations, and a menu in a custom location (a docs sidebar,
  say) keeps it when you save its settings.

After updating: to use the new tools, reconnect your AI assistant so it can
ask for the new permissions.
