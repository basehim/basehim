The Apps page has a new look, and apps are safer to install and easier to approve.

- Apps is now a searchable list with a status filter, a menu on each row and
  bulk actions, in the same style as the dashboard and the Marketplace.
- Only apps installed from a .zip upload or the Marketplace are listed. A
  folder copied into content/apps by hand is ignored (the page tells you), and
  an app whose folder was renamed or deleted is switched off and shown as
  "Files missing" instead of appearing twice.
- Permissions open in a window on the same page, in plain words, with what was
  checked for you and why the app needs each one.
- If an app's page needs a permission it doesn't have, it now asks for it
  instead of showing an error. Allow it and the page opens.

After updating: nothing to do. Apps you installed before keep working.
