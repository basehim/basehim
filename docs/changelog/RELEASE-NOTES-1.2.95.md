A fix for apps' own content types in the editor.

- In the editor, the panels for an app's own groupings (for example "Event types") and for Categories could appear empty when that kind of content doesn't use tags. Saving such an item then removed its categories and groupings. They now show and save correctly. Posts and pages were not affected.
- If an app's grouping went missing from the database, opening its screen in the admin now restores it.
- The default theme shows an item's extra details in a neat grid.

After updating: nothing to do. If you saved items of an app's content type with 1.2.94 and they lost their categories or groupings, tick them again and save.
