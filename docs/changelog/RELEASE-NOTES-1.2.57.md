Filtering for the admin data table.

- Fixed: the Category and Status filters now actually filter the list.
- New: Category and Tags are multi-select dropdowns with a search box. Pick
  several to widen the results; pick a category and a tag to narrow them.
  Large taxonomies search as you type; small ones filter instantly.
- New: a Tags column, with each tag linking straight to its edit screen.
- Changing the view, a filter, a sort or Screen Options now keeps your current
  page instead of jumping back to the first one.

After updating: nothing to do. If you have customised which columns show, enable
the new Tags column from Screen Options.
