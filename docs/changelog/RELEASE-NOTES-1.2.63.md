Quick Edit opens in a dialog, and works properly on phones.

- Quick Edit now opens in a dialog over the list instead of inside the table.
  Close it with ×, Cancel, Escape or a click outside; if you have unsaved
  changes it asks first. On phones it fills the screen, with Save and Cancel
  always in reach at the bottom.
- Fixed: on phones, tapping a field in Quick Edit (title, tags…) opened the
  keyboard and then closed it again at once. Fields now keep the keyboard
  open while you type.
- On phones, Quick Edit no longer zooms into a field when you tap it, and it
  no longer opens the keyboard by itself before you have chosen a field.
- View and Preview are now the first item in each row's ⋮ menu.
- Quick Edit's corners now match the admin menu: fields, tags, buttons and
  the Publish controls use the same, less rounded corners.
