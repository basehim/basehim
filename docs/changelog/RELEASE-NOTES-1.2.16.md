A faster Media library, a smoother image preview, and Shift+click to select a range.

The Media library now shows small copies of your images instead of downloading
every full-size photo, so it opens much faster. Clicking an image shows a
preview straight away while the full-size image loads, and lists the image's
available sizes.

When selecting files, click one and Shift+click another to select everything
in between — handy for deleting many files at once.

Also fixed: the Select button did not show the bar with the Delete button.
