A new marketplace, built like a store.

- Apps and Themes tabs on one page; the tab you came from is open.
- Large cards in a grid: app icons up to 256px, theme screenshots, with
  installs, size, developer, category and version on every card.
- Featured apps and themes get a spotlight banner; categories are one click
  away as chips.
- The details window shows installs, version, size and category up front,
  then the description, permissions, tags and links.
