The Categories widget now lines up post counts neatly, and can be shown as a
dropdown.

Post counts now sit on the right, with the category name on the left, in any
theme. The widget has a new "Display as" option: a list, or a dropdown where
choosing a category opens it. Together with "Show post counts" you can show a
plain list, a list with counts, a dropdown, or a dropdown with counts. The
Tags widget has the same options.

Counts now include only published posts, so they match what visitors find
when they open the category. Before, drafts and deleted posts were counted
too.

Your existing widgets keep their current look until you change them.

This update also restores some Customizer fixes from version 1.2.2 on sites
that were missing them.
