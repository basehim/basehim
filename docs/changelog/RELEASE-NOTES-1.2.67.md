A faster, clearer Media Library, and a media picker that reaches every file.

- **The media picker reaches your whole library.** It used to show only your
  60 newest files. It now loads 40 at a time, with a Load More button, and
  has search, type and date filters. This is the picker used everywhere:
  featured images, the logo and site icon, the customizer and the block
  editor.
- **The picker shows only what fits.** An image block lists images, a video
  block lists videos, and a gallery can take several images at once. Your
  current featured image is already selected when the picker opens.
- **The Media Library has two views.**
  - **Grid:** thumbnails, with Load More.
  - **List:** the same table as Posts and Pages, with thumbnail, file name,
    type, size, dimensions and date. It has paging and Screen Options, and
    selected files can be deleted together.
  - One set of filters drives both views: type, upload month, search and
    sort.
- **One details window.** Edit the title, alt text, caption and description,
  copy the file's URL, download or delete.
- **Deleting says exactly what happened.** For example: "2 files deleted;
  1 not deleted (you can only delete your own)". A file is only reported as
  deleted once it is really gone.
- **Safer uploads.**
  - A file's content must match its name: a web page renamed `photo.jpg` is
    refused.
  - PHP, HTML and other script or page files can never be uploaded, even if
    they are added to Settings → Media → Allowed file types.
- Clear loading, empty, "no matches" and error states, each with Retry. Works
  with the keyboard and on phones.

Nothing to do after updating. File addresses, IDs and your settings are
unchanged.
