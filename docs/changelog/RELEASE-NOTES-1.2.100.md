Fixes for lists, Customize and newer PHP versions.

- **Lists:** in the Comfortable layout, a row's action links now appear only on the row you point at. The row's highlight covers them, and nothing moves when they appear.
- **Customize → Site identity:** Logo width and the Site name and Site tagline switches now appear only when your theme supports them, so you won't see controls that do nothing.
- **Media library on phones:** long file names wrap within their space instead of running over the size and date.
- **PHP 8.5:** Basehim no longer fills your error log with "deprecated" notices on every page.

After updating: nothing to do. If you use your own theme and want the logo width and header switches, see "supports" in the theme guide.
