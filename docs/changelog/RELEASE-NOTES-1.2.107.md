A big polish pass on the lists you manage every day — posts, pages, comments,
users and any app that uses the same tables. The biggest changes are on phones
and tablets, where the lists now feel like an app.

- **One "Filter & sort" button on small screens.** The filters that used to
  stack down the page — status, category, tags — now sit behind a single
  button, with a little number when any are on. It opens a panel from the
  right with all the filters together.
- **You can finally sort on a phone.** Sorting used to live in the table
  column headers, which phones don't show — so there was no way to sort. The
  new panel has a "Sort by" control (newest, title, and so on) with an
  up/down toggle.
- **A tidier selection bar.** When you tick rows, the floating action bar has
  been rebuilt to match the rest of the admin: a clear count, labelled buttons
  with icons, and an easy way to clear the selection.
- **Lists show a placeholder while they load** instead of dimming and
  spinning, so the page doesn't jump when the new rows arrive — they land right
  where the placeholder was.

Everything on desktop works exactly as before. The Media Library has its own
screen and isn't part of this change.
