Images saved by apps now keep their alt text.

Apps that save images to your media library — Image Studio, Photo Studio,
Office, Pinout Maker, Component Builder and Video Editor — supply a description
of each image for screen readers and search engines, but it was being lost.
From this update it is saved. Images saved earlier have no alt text; you can
add it in the Media library.

Also fixed: an image edited in place (for example in Image Studio) kept its
old size in the media library. Its new dimensions are now recorded.
