New: apps can work with media and uploads without changes to Basehim itself.

- Uploads in the media library and the editor now go through Basehim's AJAX
  system, with clearer messages when a file is refused or too large.
- Apps can check, compress, rename or file uploads in folders, add thumbnail
  sizes, replace a file in place and show labels on library items.
- Apps that take their own files (packages, imports) get the same safety
  checks and a private storage folder.

After updating: nothing to do. Apps that don't use the new features work as
before.
