A new way to handle tables with lots of columns, plus a fix for the mobile
menu.

- **Wide tables now scroll sideways with the first columns pinned.** When a
  list has more columns than fit, it turns into a scrollable grid: the heading
  row stays at the top and the first columns — the tick box, the picture and
  the title — stay on the left while you scroll the rest left and right. On
  phones, lists still show as cards.
- **The mobile menu now dims the list properly.** In the last update the
  search bar and headings could flicker or disappear when you opened the menu;
  they now dim smoothly along with everything else.
