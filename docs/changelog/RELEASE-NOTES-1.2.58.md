# Basehim 1.2.58

**The Comments screen now uses the same data table as Posts and Pages.**

Moderating comments gets search, a Status filter (All, Approved, Pending, Spam,
Trash), pagination, column options and row selection — and you can **Approve**,
**Unapprove**, mark **Spam** or **Delete** several comments at once from the
selection bar or a single comment from its row menu. Deleting a comment is
permanent and says so before it happens.

This release also fixes a bug where searching comments could error on some
hosts.

Prefer the old layout? Add `?view=classic` to the Comments page for the
previous list.

Nothing else changes: Posts and Pages work exactly as before.
