More polish for the lists on phones and tablets, following 1.2.107.

- **One tidy row of controls.** Select all, search, Filter & sort and Screen
  Options now sit together on a single row instead of stacking down the page.
- **Search grows as you type.** Tap the search box and it smoothly expands to
  fill the row; the other controls step aside and come back when you're done.
- **Screen Options is back on phones** — choose which columns show and how many
  rows per page from the same place as on desktop.
- **The filter & sort panel slides in and out smoothly** instead of snapping.
- **Lists show their loading placeholder a touch longer** so a quick refresh
  reads as a load, not a flicker, on every sort, filter and page change.
- **Fixed:** choosing "Default order" in Sort now stays on Default instead of
  jumping back to the last column you sorted by.
- Slightly smaller, more consistent text throughout the lists.

Desktop is unchanged. After updating: nothing to do.
