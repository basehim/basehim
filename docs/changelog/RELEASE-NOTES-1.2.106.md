The Comments list gets a Quick View, so you can read a whole comment without
leaving the page.

- Open a comment's menu and choose **Quick View** to see the full comment —
  the list only shows the first line or so — along with who left it, their
  email and website, the post it's on and when it was posted.
- Handy for moderating: read the whole thing, then approve, mark as spam or
  delete from the same menu.
