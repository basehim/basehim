Markdown posts now open in the visual editor as blocks.

- A post written in Markdown (common for drafts made by AI tools or the API)
  opens converted into normal blocks: headings, lists, code, tables, images.
  Nothing changes until you save; "Keep Markdown" puts the original back.
- Better conversion: bold lines used as headings become headings, code inside
  numbered steps becomes a code block with the numbering kept, and Q/A line
  breaks are kept.
- Markdown saved as HTML by mistake is recognised and shows properly on the
  site instead of raw ** and * characters.
