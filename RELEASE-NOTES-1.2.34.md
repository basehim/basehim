Emails now send out of the box.

- If no From Email is set, Basehim sends as noreply@ your site's domain and
  saves it in Settings › Email. It used to fall back to the admin's own
  address (often Gmail), which most hosts refuse to send as — so sign-in
  codes and password resets never arrived.
- Settings › Email warns when the sender is on another domain.
- The SMTP password is no longer shown in the page source.
