Faster block editor, smarter tags, and a security fix.

- Security: authors and contributors could change Customizer settings
  (including custom CSS), rename or delete categories and tags, and delete
  menu items. These now need the proper admin permissions.
- Save draft (and Ctrl+S) saves without reloading the page, with a loader
  next to the button.
- Tags: type to get suggestions, press Enter or a comma to add, × to remove.
  On a saved post, changes are saved at once. New tags are created when the
  post is published. Most used and recently used tags are one click away.
- Widget previews in the editor now work for authors and editors.
- Saving a post no longer erases Open Graph details set elsewhere.
- Every remaining admin screen (media, Customizer, menus, logs and more)
  now uses the secure AJAX gateway.
