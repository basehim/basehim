A new block editor.

- The post editor now works like the WordPress block editor (Gutenberg):
  full screen, the title in the page, a toolbar that floats over the block
  you are editing, the block library and an outline on the left, and post and
  block settings on the right.
- New blocks: Table, Columns, Group (row and stack), Cover, Media & Text,
  Gallery, Video, Audio, File, Details (accordion), Pullquote, Preformatted
  and Buttons. Blocks can be placed inside each other.
- Type `/` to pick a block, use `#`, `-` or `>` to start a heading, list or
  quote, and paste from Google Docs, Word or a web page to get real blocks,
  tables included. Paste a YouTube or Vimeo link to embed it.
- Colours, font sizes, drop caps, wide and full-width layouts, anchors and
  CSS classes on every block. Shift+Alt+H lists the keyboard shortcuts.
- Posts written with the old editor open and display exactly as before.
