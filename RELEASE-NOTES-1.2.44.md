Editor and SEO improvements.

- Images uploaded from the post editor get SEO-friendly names: a file with a
  meaningless name (a phone photo like 1000477992.jpg, a pasted image.png, a
  screenshot) is named after the post, e.g. best-hiking-trails.jpg.
  Meaningful file names are kept as they are.
- Fixed: the ⋮ menus in the editor (block options and the top-right menu)
  didn't close when tapped again, most noticeably on phones.
- Shared links now show the post's featured image (or the social image set in
  its SEO settings) on Facebook, X, LinkedIn and others, with every theme.
- Pages now include <meta name="generator" content="Basehim CMS">.
