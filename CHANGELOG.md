# Changelog

Every Basehim release has two files in [`docs/changelog/`](docs/changelog/):

- **`CHANGELOG-x.y.z.md`** — what changed and why, for developers: the
  problem, the fix, the files, the tests.
- **`RELEASE-NOTES-x.y.z.md`** — the short version site owners see on
  Admin → Updates.

Releases are numbered *major.minor.patch*. A patch release carries only the
files that changed and installs on the release before it; updates are applied
in order. [`notes-1.0-to-1.2.46.md`](docs/changelog/notes-1.0-to-1.2.46.md) is
the earlier single-file changelog, kept for its known-issues list and schema
history.
