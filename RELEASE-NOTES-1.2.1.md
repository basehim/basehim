A guide for building themes.

`docs/THEME-DEVELOPMENT.md` covers the manifest, templates and the data they
receive, Customizer options and how they reach CSS, menus, widgets, the
front-end helpers, and what happens when a theme breaks.

Documentation only — no code has changed, so this cannot affect a running site.

The README has also had references to the desktop agent feature removed. That
was taken out of core in 1.0.5 and the documentation had been left behind,
describing endpoints and a service that no longer exist.
